# Counter_Base

Local research app for your own documents. The app runs on this computer.

## Downloads

Download the latest release for your platform from the [Releases](https://github.com/Zayn-InfinityBox/Counter_Base-Releases/releases) page.

| Platform | File |
|----------|------|
| **macOS** | `Counter_Base-macOS.zip` |
| **Windows** | `Counter_Base-Windows.zip` |

## Installation

### macOS
1. Download and extract the ZIP file
2. Open `Counter_Base.app`
3. If macOS blocks the app, right-click it and choose Open

### Windows
1. Download and extract the ZIP file
2. Run `Counter_Base.exe`

Models download the first time you ask a question and stay on this computer.
